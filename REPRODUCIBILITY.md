# Reproducibility

## Environment

Create the recommended environment:

```bash
conda env create -f environment.yml
conda activate argentina-cre-plasmidome-2021
npm install
```

The core validation scripts use Python standard-library modules and Node.js only. BLAST+ is required only for optional reference all-vs-all validation.

## Public Validation Workflow

Run:

```bash
npm run validate
```

Expected result:

- `validation/input_inventory.tsv`
- `validation/reference_plasmid_validation.md`
- `validation/release_validation.md`
- `validation/release_hashes.tsv`
- `validation/figure3_sankey_validation.md`
- `validation/figure3_sankey_counts.tsv`
- `validation/figure3_sankey_regenerated_svg/RECAPTARII_Figure3_sankey_final.svg`

## Byte Identity

Frozen publication PDF, PPTX, PNG, and SVG files are retained. The Figure 3 SVG regenerated by the public workflow validates content and counts, but byte identity is not required because SVG serialization can differ across runtime environments.
