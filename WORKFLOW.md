# Workflow

This document describes the final public workflow and retained scientific lineage.

## 1. Reference Plasmid Collection

Input:

- `data/accession_lists/reference_plasmids_34.tsv`
- `data/accession_lists/reference_inventory_34.tsv`
- `data/plasmid_references/references_34/*.fasta`
- `data/plasmid_references/genbank_missing/*.fasta`

Output:

- Complete 34-plasmid reference FASTA collection.
- Reference validation report generated by `scripts/03_tables/build_input_inventory.py`.

Used later by:

- Reference clustering.
- Representative plasmid selection.
- Short-read backbone projection.
- Figure 2 provenance.

## 2. Reference Clustering

Input:

- 34 reference FASTAs.

Script:

- `scripts/01_reference_plasmid_workflow/cluster_reference_plasmids.sh`

Retained provenance:

- `data/provenance/ps0007_reference_workflow/reference_workflow_comparison.md`
- `data/provenance/ps0007_reference_workflow/updated_cluster_table_PS0007.tsv`
- `data/provenance/ps0007_reference_workflow/group_summary_PS0007.tsv`
- `data/provenance/ps0007_reference_workflow/critical_checks_PS0007.tsv`

Output:

- Validated PS0007 reference backbone organization.
- Full 34-reference table with C01-C06 and singleton labels S01, S03, S04, S05, and S06.

Used later by:

- Representative plasmid selection.
- Short-read backbone projection.
- Figure 2 source interpretation.

## 3. Representative Selection

Input:

- Pairwise plasmid comparison from reference clustering.
- Cluster membership table.

Retained report:

- `data/provenance/ps0007_reference_workflow/representative_selection_report.md`

Output:

- Selected representative plasmid for each recurrent cluster or singleton.

Used later by:

- Short-read projection.
- Final backbone assignment curation.

## 4. Short-Read Projection

Input:

- Representative plasmid backbones.
- Short-read assembly inventory.

Retained provenance:

- `data/provenance/ps0007_short_read_assignment/coverage_summary_PS0007.tsv`
- `data/provenance/ps0007_short_read_assignment/backbone_assignments_PS0007.tsv`
- `data/provenance/ps0007_short_read_assignment/delta_rule_impact_PS0007.tsv`

Assignment criterion:

- At least 95% nucleotide identity.
- At least 70% reference coverage.

Output:

- Full coverage summary.
- Raw backbone assignments.
- Small-plasmid review table.

Used later by:

- Curated final assignments.
- Figure 2 source data.
- Figure 3 Sankey input.

## 5. Manual Biological Curation

Input:

- Raw PS0007 assignments.
- Candidate hits.
- Small-plasmid review table.
- Curated manuscript table.

Curated outputs:

- `data/derived/all_candidate_hits.tsv`
- `data/derived/excluded_small_plasmid_hits.tsv`
- `data/derived/final_assignments.tsv`

Important curation rules:

- Small-plasmid hits are not retained when a larger valid carbapenemase-bearing backbone assignment exists, unless the small plasmid is the confirmed carbapenemase-bearing plasmid for that isolate.
- Carbapenemase-negative isolates are excluded from Figure 3.
- Carbapenemase-positive isolates without an assigned plasmid backbone are excluded from Figure 3.
- Dual-backbone isolates are expanded only at the backbone-flow level.

Used later by:

- Final Figure 3 Sankey input.
- Figure 2 epidemiological source table.
